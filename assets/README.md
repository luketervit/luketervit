# Profile artwork

Original SVG composition for Luke Tervit's GitHub profile, adapted from his personal website's visual identity. All substantive copy and links live in the root README.

- `header-light.svg` / `header-dark.svg`: 1200 × 396 desktop artwork.
- `header-mobile-light.svg` / `header-mobile-dark.svg`: 600 × 440 mobile artwork.
- The README selects by colour scheme and viewport width using `<picture>`.
- Static vectors, with no scripts, external image services, tracking or animation.
- Lettering uses DM Sans (medium) and Instrument Serif (regular), converted to paths so GitHub renders the intended type consistently. Screen-reader equivalents are in the README alt text and SVG title/description.
- Fonts sourced from the Google Fonts repositories: `google/fonts/ofl/dmsans` and `google/fonts/ofl/instrumentserif`. Their SIL Open Font Licenses are included in `FONT-LICENSES.txt`.
